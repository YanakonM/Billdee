## 1. การติดตั้งและเปิดใช้งานครั้งแรก

Billdee ใช้ได้ 2 แบบ:

| แบบ | เหมาะกับ | ข้อมูลเก็บที่ |
|---|---|---|
| **โปรแกรม Windows** (แนะนำ) | ใช้หน้าร้าน/ออฟฟิศเป็นหลัก | ไฟล์ SQLite ในเครื่อง — ปิดเบราว์เซอร์/ล้าง cache ก็ไม่หาย |
| **เว็บเบราว์เซอร์** | ลองใช้ / เครื่องเสริม | IndexedDB ของเบราว์เซอร์ (ต้องสำรองข้อมูลสม่ำเสมอ) |

**ติดตั้งบน Windows:**
1. ไปที่หน้า Releases ของโปรเจกต์บน GitHub → ดาวน์โหลดไฟล์ `.msi` หรือ `.exe` ตัวล่าสุด
2. ดับเบิลคลิกติดตั้ง → เปิดโปรแกรม "Billdee"
3. โปรแกรมทำงาน **ออฟไลน์ได้สมบูรณ์** — ฟอนต์และทรัพยากรทั้งหมดฝังมาในตัว

**ใช้ผ่านเบราว์เซอร์ (โหมดพัฒนา/ทดลอง):** ดู [ส่วนที่ 16](#16-สำหรับนักพัฒนา)

> 💡 เปิดใช้งานได้ **ทีละแท็บเดียว** — ถ้าเปิดซ้ำอีกแท็บ ระบบจะขึ้นเตือน
> "ระบบเปิดอยู่ในแท็บอื่นแล้ว" เพื่อป้องกันข้อมูลตีกัน

## 2. ตั้งค่าเริ่มต้น

เข้าเมนู **ตั้งค่า** (ไอคอนเฟือง ล่างสุดของแถบซ้าย) — ทำ 3 แท็บแรกให้ครบก่อนออกบิลจริง:

### 2.1 ข้อมูลบริษัท
| ช่อง | คำอธิบาย |
|---|---|
| โลโก้บริษัท | อัปโหลดรูป (PNG/JPG) — จะพิมพ์บนหัวเอกสาร A4 ทุกประเภท |
| ชื่อบริษัท (ไทย/อังกฤษ) | แสดงบนหัวเอกสาร |
| **เลขประจำตัวผู้เสียภาษี** | 13 หลัก — ระบบ**ตรวจ check digit จริง** ถ้าเลขผิดจะเตือนตอนบันทึก และจะ**ออกใบกำกับภาษีไม่ได้**จนกว่าจะถูกต้อง |
| รหัสสาขา | เว้นว่างหรือ `00000` = สำนักงานใหญ่, อื่นๆ = สาขาที่ XXXXX (พิมพ์บนใบกำกับ) |
| ที่อยู่ / เบอร์ / อีเมล | แสดงในส่วน "ผู้ออก" ของเอกสาร |

### 2.2 บัญชีธนาคาร
กรอกธนาคาร + ชื่อบัญชี + เลขบัญชี — จะแสดงบนบิลเมื่อเลือกช่องทางชำระ "โอนเงิน"

**PromptPay ID** (เบอร์มือถือ 10 หลัก / เลขบัตรประชาชน หรือเลขภาษี 13 หลัก / e-Wallet 15 หลัก)
→ บิลที่ชำระแบบโอนเงินจะมี **QR พร้อมเพย์ระบุยอดเงิน** พิมพ์ให้อัตโนมัติ ลูกค้าสแกนจ่ายได้ทันที

### 2.3 ตั้งค่าใบเสร็จ
| ตัวเลือก | คำอธิบาย |
|---|---|
| คำนำหน้าเลขที่เอกสาร | เช่น `INV` → เอกสารจะรันเป็น INV-000001, INV-000002, … |
| เลขลำดับถัดไป | ตั้งเลขเริ่มต้นได้ (เช่นย้ายจากระบบเดิมที่ค้างเลข 250 → ใส่ 251) |
| อัตราภาษี VAT (%) | ค่าเริ่มต้น 7 |
| **รูปแบบราคาในใบกำกับภาษี** | ⭐ สำคัญ — เลือกให้ตรงกับวิธีตั้งราคาของร้าน:<br>• **ราคายังไม่รวม VAT** — ระบบบวก VAT เพิ่มท้ายบิล (ขาย 100 → เก็บ 107)<br>• **ราคารวม VAT แล้ว** — ระบบถอด VAT ออกจากยอด (ขาย 107 → มูลค่า 100 + VAT 7) เหมาะกับร้านค้าปลีกที่ติดป้ายราคารวมภาษี |
| รูปแบบวันที่ | พ.ศ. (ไทย) หรือ ค.ศ. — มีผลทั้งหน้าจอและเอกสารพิมพ์ |
| การติดตามสต็อก | เกณฑ์แจ้งเตือนใกล้หมด + เปิด/ปิดการแจ้งเตือน |

กด **บันทึก** มุมขวาบนทุกครั้งหลังแก้ไข

## 3. แดชบอร์ด

หน้าแรกเมื่อเปิดโปรแกรม สรุปภาพรวมวันนี้:

- **การ์ดสถิติ 4 ใบ** — ใบเสร็จวันนี้ / ยอดขายวันนี้ (หักใบลดหนี้แล้ว) / ลูกค้า+สินค้าทั้งหมด / ยอดค้างชำระ
  - ยอดขาย**ไม่นับ**ใบส่งของและเอกสารที่ถูกยกเลิก
- **ใบเสร็จล่าสุด 5 ใบ** — คลิกแถวเพื่อเปิดดูรายละเอียดทันที
- **ลูกค้ายอดซื้อสูงสุด 5 อันดับ**
- **แจ้งเตือนค้างชำระ** — บิลค้างจ่ายเกิน 7 วัน (คลิกเพื่อเปิดบิล)
- **สินค้าใกล้หมด** — ตามเกณฑ์ที่ตั้งไว้ (เฉพาะสินค้าที่ติดตามสต็อค)
- **แถบเตือนสำรองข้อมูล** — โผล่เมื่อไม่ได้สำรองเกิน 7 วัน กด "สำรองข้อมูลตอนนี้" ได้เลย
- **ทางลัด** — ปุ่มลัดไปยังหน้าที่ใช้บ่อย

## 4. จัดการสินค้าและสต็อค

เมนู **สินค้า**

### 4.1 เพิ่มสินค้า
1. กด **+ เพิ่มสินค้า**
2. รหัสสินค้า (P-0001, P-0002, …) ระบบรันให้อัตโนมัติ
3. กรอกชื่อ* ราคา* หน่วย หมวดหมู่ รายละเอียด
4. **บาร์โค้ด** — พิมพ์เอง หรือกดไอคอนสแกนข้างช่องเพื่อใช้กล้อง/เครื่องสแกน USB
   - ถ้าบาร์โค้ดซ้ำกับสินค้าอื่น ระบบจะเตือนก่อน (เครื่องสแกนจะเจอตัวเดิมเสมอ)
5. **จำนวนคงเหลือ (สต็อค)**:
   - กรอกตัวเลข = เปิดติดตามสต็อค (ตัดอัตโนมัติเมื่อขาย)
   - **เว้นว่าง = ไม่ติดตามสต็อค** (เหมาะกับงานบริการ/ค่าแรง) — จะแสดง "-" ในตาราง

### 4.2 สแกนบาร์โค้ดจากหน้าหลัก
กด **สแกนบาร์โค้ด** บนหัวหน้า → เลือกโหมด **กล้อง** หรือ **พิมพ์** (รองรับเครื่องสแกน USB — เสียบแล้วยิงได้เลย)
- ถ้าบาร์โค้ด**มีอยู่แล้ว** → เปิดหน้าแก้ไขสินค้าตัวนั้น
- ถ้า**ยังไม่มี** → เปิดฟอร์มเพิ่มสินค้าใหม่ พร้อมกรอกบาร์โค้ดให้แล้ว

### 4.3 รับสินค้าเข้า / ปรับสต็อค / ดูประวัติ 📦
กดไอคอน **กล่อง+** ในแถวสินค้า → modal จัดการสต็อค:

| การทำรายการ | ใช้เมื่อ |
|---|---|
| 📥 **รับสินค้าเข้า (+)** | ของเข้าจากซัพพลายเออร์ — ใส่จำนวน + หมายเหตุ |
| 📤 **ตัดสต็อคออก (−)** | ของเสีย/หาย/เบิกใช้เอง — ถ้าตัดเกินที่มี ระบบถามยืนยัน (เหลือ 0) |
| 🎯 **ตั้งยอดใหม่** | นับสต็อคจริงแล้วปรับให้ตรง — ใส่ยอดที่นับได้ ระบบคำนวณส่วนต่างให้ |

ด้านล่างแสดง**ประวัติการเคลื่อนไหว 15 รายการล่าสุด** — ทุกการขาย/คืน/รับเข้า/ตัดออก/ยกเลิกบิล
ถูกบันทึกอัตโนมัติพร้อมวันที่ ยอดก่อน→หลัง และหมายเหตุ

สินค้าที่ไม่ติดตามสต็อค จะมีปุ่ม **เริ่มติดตาม** — ใส่ยอดเริ่มต้นเพื่อเข้าระบบสต็อค

### 4.4 นำออก / นำเข้า ข้อมูลสินค้า (ย้ายสต็อคไปอีกเครื่อง) 🔁
กด **นำออก / นำเข้า** บนหัวหน้าสินค้า — ย้ายเฉพาะสินค้า/สต็อค **ไม่แตะลูกค้าและใบเสร็จ**
ของเครื่องปลายทาง (ต่างจาก "สำรอง/กู้คืน" ในหน้าตั้งค่า ที่เขียนทับทั้งฐานข้อมูล)

**นำออก**
| รูปแบบ | ได้อะไร | เหมาะกับ |
|---|---|---|
| **JSON** | ทุกฟิลด์ + ประวัติการเคลื่อนไหวสต็อค | ย้ายไปอีกเครื่องให้เหมือนเดิมเป๊ะ |
| **Excel / CSV** | ตารางสินค้า หัวคอลัมน์ภาษาไทย | แก้ราคา/จำนวนทั้งแผงใน Excel แล้วนำเข้ากลับ |

**นำเข้า** — รับได้ทั้ง 2 แบบ ระบบจับคู่สินค้าเดิมด้วย **บาร์โค้ด → รหัส → ชื่อ**
จึงนำเข้าไฟล์เดิมซ้ำได้โดยไม่เกิดรายการซ้ำ (รหัสชนกันระบบออกรหัสใหม่ให้เอง)
- 🔀 **รวมกับของเดิม** (แนะนำ) — มีอยู่แล้วอัปเดต, ไม่มีเพิ่มใหม่
- 🗑️ **ล้างของเดิมแล้วแทนที่** — ลบสินค้าทั้งหมดในเครื่องก่อน (ควรกดนำออก JSON เก็บไว้ก่อน)
- ☑️ **อัปเดตจำนวนคงเหลือตามไฟล์** — ไม่ติ๊กก็ได้ ถ้าอยากย้ายแค่รายชื่อ/ราคาแต่คงสต็อคเดิมไว้
- ช่องที่เว้นว่างในไฟล์จะ**ไม่ลบ**ข้อมูลเดิมทิ้ง

> 💡 ไฟล์ CSV เปิดด้วย Excel ได้ทันที ภาษาไทยไม่เพี้ยน

### 4.5 กติกาการตัดสต็อคอัตโนมัติ
- ✅ **ตัด** เมื่อบันทึกใบเสร็จ/ใบกำกับภาษี และเมื่อแปลงใบเสนอราคาเป็นใบเสร็จ
- ❌ **ไม่ตัด** เมื่อออกใบส่งของ (กันตัดซ้ำกรณีออกใบส่งของ+ใบเสร็จคู่กัน)
- 🔄 **คืนอัตโนมัติ** เมื่อยกเลิกใบเสร็จ
- ⚠️ ขายเกินสต็อค → ระบบเตือนก่อนบันทึก (เลือกไปต่อได้ สต็อคจะหยุดที่ 0)
- ✏️ **การแก้ไขบิลย้อนหลังไม่ปรับสต็อค** — ถ้าแก้จำนวนในบิลเก่า ให้ปรับสต็อคเองที่หน้าสินค้า

## 5. จัดการลูกค้า

เมนู **ลูกค้า**

### 5.1 เพิ่ม/แก้ไขลูกค้า
- รหัสลูกค้า (C-0001, …) รันอัตโนมัติ
- ชื่อลูกค้า* / ชื่อร้าน / เบอร์ / อีเมล / หมายเหตุ
- **เลขประจำตัวผู้เสียภาษี + รหัสสาขา** — จำเป็นถ้าจะออก**ใบกำกับภาษี**ให้ลูกค้ารายนี้
  (ระบบตรวจ check digit — เลขผิดจะเตือนทันทีตอนบันทึก)
- **ที่อยู่** — จำเป็นสำหรับใบกำกับภาษีเช่นกัน
- ☑ **ลูกค้าสมาชิก (Member)** — ติดป้าย ⭐ และกรองดูเฉพาะสมาชิกได้

### 5.2 เครื่องมือในหน้ารายชื่อ
- **ค้นหา** ชื่อ / ร้าน / เบอร์ / รหัส
- **ตัวกรองกลุ่ม**: ทั้งหมด / มียอดค้างชำระ / ชำระครบแล้ว / สมาชิก
- คอลัมน์ **ยอดซื้อรวม + ค้างชำระ** คำนวณสดจากบิลจริง (ไม่นับบิลยกเลิก/ใบส่งของ)
- ไอคอน 👁 **ดูประวัติ** — สถิติ + รายการบิลทั้งหมดของลูกค้ารายนั้น คลิกบิลเพื่อเปิดได้

> 💡 ตอนออกบิล ถ้าพิมพ์ชื่อลูกค้าใหม่ที่ไม่เคยมี ระบบจะถามว่า
> "ต้องการบันทึกเป็นลูกค้าใหม่หรือไม่?" — สร้างลูกค้าอัตโนมัติโดยไม่ต้องมาหน้านี้ก่อน

## 6. สร้างใบเสร็จ / ใบกำกับภาษี / ใบส่งของ

เมนู **สร้างใบเสร็จ** — หน้าหลักของระบบ

### 6.1 เลือกประเภทเอกสารและวันที่
| ประเภท | VAT | ตัดสต็อค | เงื่อนไข |
|---|---|---|---|
| ใบเสร็จรับเงิน (Receipt) | ไม่มี | ✅ | — |
| ใบกำกับภาษี (Tax Invoice) | ✅ ตามตั้งค่า | ✅ | เลขภาษีบริษัท+ลูกค้าถูกต้อง และลูกค้ามีที่อยู่ |
| ใบส่งของ (Delivery Note) | ไม่มี | ❌ | ใช้เลขรันแยก (DO-xxxxxx) |

**เลขที่เอกสาร** — ระบบจองเลขอัตโนมัติตอนกดบันทึก (กันเลขซ้ำแม้กดรัว)
พิมพ์เลขเองได้ แต่**ถ้าซ้ำกับที่มีอยู่ ระบบจะไม่ให้บันทึก**

### 6.2 เลือกลูกค้า
พิมพ์ชื่อ/ร้าน/เบอร์ในช่องค้นหา → เลือกจากรายการ (แสดงข้อมูลครบ + วันซื้อล่าสุด)
หรือพิมพ์ชื่อใหม่เฉยๆ → ระบบเสนอบันทึกเป็นลูกค้าใหม่ให้ตอนเซฟ
*ออกใบเสร็จแบบไม่ระบุลูกค้าก็ได้ (ขายหน้าร้าน)*

### 6.3 เพิ่มรายการสินค้า (3 วิธี)
1. **ค้นหาสินค้าที่บันทึกไว้** — พิมพ์ชื่อ/บาร์โค้ด/รหัส/หมวดหมู่ → เลือก → เพิ่มแถวพร้อมราคา
   - พิมพ์**ตัวอักษรแรก**ก็ขึ้นผลทันที และคลิกช่องค้นหาเฉยๆ จะเห็น**สินค้าล่าสุด**ให้เลือกเลย
   - รหัส/บาร์โค้ดที่**ตรงเป๊ะมาก่อนเสมอ** รองลงมาคือชื่อที่ขึ้นต้นด้วยคำค้น
   - แต่ละรายการแสดง**จำนวนคงเหลือ**เป็นป้ายสี (เขียว = ปกติ, เหลือง = ใกล้หมด, แดง = สต็อคหมด) —
     ของหมดยังเลือกได้ แต่จะถูกจัดไว้ล่างสุด
   - ค้นหลายคำได้ (เช่น `ปูน ตราเสือ`) และไม่สนตัวพิมพ์เล็ก-ใหญ่/ขีดคั่น (`p0001` = `P-0001`)
   - ⌨️ กด **↑ ↓** เลือก แล้ว **Enter** เพิ่มเข้าบิล — เคอร์เซอร์ค้างในช่องเดิม ยิงรายการต่อได้เรื่อยๆ
2. **สแกน** — กล้องหรือเครื่องสแกน USB
3. **+ เพิ่มรายการ** — พิมพ์อิสระ (สินค้า/บริการที่ไม่ได้บันทึกไว้)

- เลือก/สแกนสินค้า**ตัวเดิมซ้ำ → จำนวนบวกเพิ่มในแถวเดิม** (ไม่แตกแถวใหม่)
- แก้จำนวน/ราคา/**ส่วนลดต่อแถว** (เป็นจำนวนเงิน) ได้ทุกช่อง — ยอดรวมคำนวณสด
- ⛔ ส่วนลดมากกว่ายอดของแถว = บันทึกไม่ได้ (ระบบบอกชื่อแถวที่ผิด)
- สินค้าหมดสต็อค → เตือนตอนเพิ่ม และเตือนสรุปอีกครั้งก่อนบันทึก

### 6.4 สรุปยอดท้ายบิล
- **ส่วนลดท้ายบิล** — หักจากยอดรวมก่อนคิด VAT
- ใบกำกับภาษีจะแสดงบรรทัด VAT ตามโหมดที่ตั้งไว้ (บวกเพิ่ม หรือถอดจากราคารวม —
  โหมดรวมจะโชว์ "มูลค่าสินค้าก่อน VAT" ให้ด้วย)
- **หักภาษี ณ ที่จ่าย** ☑ — เลือกอัตรา 1/2/3/5/10% ระบบคำนวณจากฐานก่อน VAT
  หลังหักส่วนลด แสดง "ยอดชำระสุทธิ" ที่ลูกค้าต้องจ่ายจริง
- ยอดเงินแปลงเป็น**ตัวหนังสือไทย**ท้ายบิลอัตโนมัติ

### 6.5 การชำระเงิน
| ช่องทาง | สิ่งที่ได้ |
|---|---|
| 💵 เงินสด | ช่อง "รับเงินมา" → คำนวณ**เงินทอน**ให้ (เตือนถ้ารับเงินไม่พอ) |
| 🏦 โอนเงิน | แสดงเลขบัญชีบนบิล + **QR พร้อมเพย์ระบุยอด** (ถ้าตั้ง PromptPay ID ไว้) |
| 📄 เช็ค / 💳 บัตรเครดิต | ระบุวิธีชำระบนบิล |

เลือก**สถานะ**: ชำระแล้ว / ค้างชำระ (ไปตามเก็บต่อได้ที่หน้าประวัติ+แดชบอร์ด)
ช่อง **ผู้จัดทำ** จำชื่อล่าสุดให้อัตโนมัติ

### 6.6 บันทึกและพิมพ์
- **บันทึก** — เซฟแล้วไปหน้าประวัติ
- **บันทึก & พิมพ์** — เซฟแล้วเปิดตัวอย่างพร้อมพิมพ์ทันที
  - หลังเซฟ ถ้าแก้ไขอะไรต่อ ปุ่มบันทึกจะกลับมาให้กด — **อัปเดตใบเดิม** ไม่สร้างใบซ้ำ
- **ขนาดกระดาษ** (จำค่าที่เลือกไว้): `A4` `A5` `Letter`, **`ต่อเนื่อง 9×5.5" (หัวเข็ม)`**, **`ต่อเนื่อง 9×11" (LQ-310)`** สำหรับเครื่องพิมพ์ดอทเมทริกซ์ และใบเสร็จย่อความร้อน `80mm` `58mm`
  - โหมด **9×5.5"** จัดเลย์เอาต์กระชับ (ตัดแถวว่าง ย่อขอบ/ลายเซ็น) ให้บิลทั่วไปจบพอดี 1 หน้าครึ่งแผ่น และพิมพ์หน้าเดียว (สำเนาได้จากกระดาษเคมีหลายชั้นของเครื่องหัวเข็มเอง) — บิลที่มีรายการยาวมากจะไหลต่อหน้าถัดไปตามธรรมชาติของกระดาษต่อเนื่อง
  - ตั้งค่าเครื่องพิมพ์: ลงไดรเวอร์ LQ-310 (ESC/P2) → Windows Printers → Print server properties → สร้าง custom form ขนาด 9×5.5 หรือ 9×11 นิ้วตามกระดาษจริง → ตั้งเป็นค่าเริ่มต้นของเครื่อง
- ใบกำกับภาษี A4 พิมพ์ **2 แผ่นอัตโนมัติ**: ต้นฉบับ (Original) + สำเนา (Copy)
- **ดูตัวอย่าง** ก่อนพิมพ์ได้เสมอ / ปุ่ม **แชร์** ส่งสรุปบิลเข้า LINE หรือคัดลอกข้อความ

## 7. ประวัติใบเสร็จ

เมนู **ประวัติใบเสร็จ** — เอกสารทุกใบที่เคยออก

### 7.1 ค้นหาและกรอง
- ค้นหาจากเลขที่ / ชื่อลูกค้า
- กรองตามสถานะ: ทุกสถานะ / ชำระแล้ว / ค้างชำระ / ยกเลิก
- กรองตามที่มา: สร้างเอง / แปลงจากใบเสนอราคา
- แถบสรุปแสดงจำนวน + ยอดรวมของรายการที่กรอง (ไม่นับใบที่ยกเลิก)

### 7.2 การจัดการต่อใบ (ไอคอนท้ายแถว)
| ปุ่ม | ทำอะไร |
|---|---|
| 👁 ดู | เปิดตัวอย่างเอกสาร |
| ✏️ แก้ไข | เปิดกลับในหน้าสร้างใบเสร็จ แก้ได้ทุกช่อง เลขที่เดิมคงไว้ (สต็อคไม่ปรับย้อนหลัง) |
| 🖨 พิมพ์ | พิมพ์ซ้ำทุกขนาดกระดาษ |
| ⭕ **ยกเลิกเอกสาร** | Void ตามหลักเอกสารภาษี — ใบยังอยู่ในระบบ (ประทับ "ยกเลิก"), **คืนสต็อคอัตโนมัติ**, ถ้าบิลมาจากใบเสนอราคาจะ**ปลดล็อกให้แปลงใหม่ได้**, ถ้ามีใบลดหนี้ผูกอยู่จะเตือนก่อน |
| 🗑 ลบถาวร | โผล่เฉพาะใบที่**ยกเลิกแล้ว**เท่านั้น — ป้องกันการลบเอกสารภาษีทิ้งตรงๆ |

- คลิก **badge สถานะ** เพื่อสลับ ชำระแล้ว ⇄ ค้างชำระ ได้เลย (ใบยกเลิกสลับไม่ได้)
- เอกสารที่ยกเลิกจะพิมพ์มีคำว่า **(ยกเลิก)** กำกับบนหัวเอกสาร

## 8. ใบเสนอราคา

เมนู **ใบเสนอราคา** — เลขรันแยก (QT-xxxxxx)

**สร้าง:** กด **สร้างใบเสนอราคา** → เหมือนหน้าสร้างบิล (ลูกค้า + รายการ + ส่วนลดต่อแถว)
- **ใช้ได้ถึง** — วันหมดอายุ (ค่าเริ่มต้น +30 วัน)
- บันทึกโดยไม่ระบุลูกค้าได้ แต่ระบบจะถามยืนยันก่อน

**วงจรสถานะ:** `รอตอบรับ` → ✔ `ตอบรับแล้ว` / ✖ `ปฏิเสธ` → ➡ `แปลงเป็นใบเสร็จแล้ว`

| ปุ่ม | ทำอะไร |
|---|---|
| ✔ / ✖ | บันทึกผลตอบรับจากลูกค้า (เฉพาะใบที่รอตอบรับ) |
| ➡ แปลงเป็นใบเสร็จ | สร้างใบเสร็จจริงจากใบเสนอราคา — ได้เลข INV ใหม่, **ตัดสต็อคทันที**, สถานะเริ่มเป็น "ค้างชำระ", หมายเหตุอ้างอิงเลข QT เดิม |
| ✏️ แก้ไข | แก้ได้ทุกใบที่ยังไม่ถูกแปลง — สถานะและลำดับเดิมคงไว้ |
| 🖨 พิมพ์ | ฟอร์มใบเสนอราคา A4 พร้อมช่องลงนามผู้เสนอ/ผู้อนุมัติ |

> ถ้าใบเสร็จที่แปลงไปถูก**ยกเลิก**ภายหลัง ใบเสนอราคาต้นทางจะถูกปลดล็อกกลับเป็น
> "ตอบรับแล้ว" ให้แปลงใหม่ได้อัตโนมัติ

## 9. ใบลดหนี้ / ใบเพิ่มหนี้

เมนู **ใบลดหนี้/เพิ่มหนี้** — สำหรับปรับยอดบิลที่ออกไปแล้ว (คืนสินค้า, คิดราคาผิด, เพิ่มค่าขนส่ง ฯลฯ)

**สร้าง:**
1. เลือกปุ่ม **ใบลดหนี้** (CN-xxxxxx) หรือ **ใบเพิ่มหนี้** (DN-xxxxxx)
2. **อ้างอิงใบเสร็จ** — เลือกได้ทั้งบิลที่ชำระแล้วและค้างชำระ (ยกเว้นบิลที่ถูกยกเลิก)
3. กรอก**เหตุผล*** (บังคับ — ต้องระบุตามหลักสรรพากร)
4. กรอก**จำนวนเงิน**ที่ลด/เพิ่ม
   - ลดหนี้เกินยอดบิลเดิมไม่ได้
   - ถ้าบิลอ้างอิงเป็น**ใบกำกับภาษี** ระบบ**แยกมูลค่า + VAT ของผลต่าง**ให้อัตโนมัติ
     และแสดงบนเอกสารพิมพ์ครบตามแบบฟอร์มภาษี

**ผลต่อรายงาน:** ยอดขายในแดชบอร์ด/รายงานจะถูก**หักใบลดหนี้ / บวกใบเพิ่มหนี้**ให้อัตโนมัติ

## 10. รายงานและการส่งออกข้อมูล

เมนู **รายงาน**

### 10.1 เลือกช่วงเวลา
`สัปดาห์นี้` (7 วันล่าสุด) · `เดือนนี้` (วันที่ 1 → วันนี้) · `รายปี` (เลือกปีย้อนหลังที่มีข้อมูลได้) ·
`กำหนดเอง` (เดือนถึงเดือน ข้ามปีได้)

### 10.2 ตัวเลขที่แสดง
- **ยอดขายรวม (หลังหักลดหนี้)** — ไม่รวมใบส่งของและใบที่ยกเลิก, หัก CN / บวก DN แล้ว
  (แสดงยอดลดหนี้/เพิ่มหนี้กำกับใต้ตัวเลข)
- ชำระแล้ว / ค้างชำระ (ค้างชำระคิดจากยอดสุทธิหลังหัก ณ ที่จ่าย) / เฉลี่ยต่อใบ

### 10.3 แท็บวิเคราะห์
- 📊 **ยอดขาย** — กราฟแท่งรายวัน (สัปดาห์/เดือน) หรือรายเดือน (ปี/กำหนดเอง)
- 👥 **ลูกค้า** — Top 10 พร้อมสัดส่วน % ของยอดขาย
- 📦 **สินค้า** — Top 10 สินค้าขายดี พร้อมจำนวนที่ขาย

### 10.4 ส่งออกไฟล์
- **CSV** — สรุปรายใบ (เลขที่/วันที่/ลูกค้า/ประเภท/ยอด/สถานะ) เปิดใน Excel/Google Sheets ได้
  — ชื่อที่มี "ลูกน้ำ" หรือขึ้นบรรทัดใหม่ไม่ทำให้คอลัมน์เพี้ยน (escape ตามมาตรฐาน)
- **Excel** — ละเอียดถึงระดับ**รายการสินค้าในแต่ละบิล** + ที่อยู่ + VAT + ช่องทางชำระ

## 12. สำรองและกู้คืนข้อมูล

**ตั้งค่า → สำรอง/กู้คืน**

### 12.1 ส่งออก (Export)
กดปุ่มเดียว → ได้ไฟล์ `billdee-backup-YYYY-MM-DD.json` ครบทุกอย่าง:
ลูกค้า สินค้า บิลทุกใบ ใบเสนอราคา ใบลดหนี้ ประวัติสต็อค และการตั้งค่า

### 12.2 นำเข้า (Import)
เลือกไฟล์สำรอง → ระบบ**ตรวจไฟล์ก่อน** (ไฟล์เสีย/ไม่ใช่ของ Billdee = ไม่แตะข้อมูลเดิม)
→ ถามยืนยัน → **สำรองข้อมูลปัจจุบันให้อีกชุดโดยอัตโนมัติ**ก่อนเขียนทับ
→ กู้คืนพร้อม**เชื่อมความสัมพันธ์ใหม่ทั้งหมด** (บิล↔ลูกค้า↔สินค้า↔ใบลดหนี้ ไม่ชี้ผิดตัว)

ใช้ไฟล์เดียวกันนี้**ย้ายข้อมูลข้ามโหมดเก็บข้อมูล**ได้ (เช่น IndexedDB → Supabase)

### 12.3 สำรองอัตโนมัติลงโฟลเดอร์ (แนะนำ — Chrome/Edge)
1. กด **เลือกโฟลเดอร์สำรองอัตโนมัติ** → ชี้ไปโฟลเดอร์ที่ sync กับ Google Drive/OneDrive หรือ USB
2. ระบบเขียนไฟล์สำรองให้**วันละครั้ง**โดยอัตโนมัติเมื่อเปิดใช้งาน
3. หลังเปิดเบราว์เซอร์ใหม่ ถ้าเบราว์เซอร์ขอสิทธิ์ซ้ำ แดชบอร์ดจะขึ้นแถบ
   "สำรองอัตโนมัติรอการยืนยัน" — กดปุ่มเดียวจบ

> ⚠️ โหมดเบราว์เซอร์: ข้อมูลอยู่ใน IndexedDB — **ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหาย**
> ตั้งสำรองอัตโนมัติไว้เสมอ (แอป Windows ปลอดภัยกว่าเพราะเก็บเป็นไฟล์ SQLite)

## 13. ที่เก็บข้อมูล

**ตั้งค่า → ที่เก็บข้อมูล** — เลือกได้ 4 แบบ:

| โหมด | เหมาะกับ | หมายเหตุ |
|---|---|---|
| **SQLite** (อัตโนมัติในแอป Windows) | เครื่องเดียว | ไม่ต้องตั้งอะไร ปลอดภัยสุด |
| **IndexedDB** (ค่าเริ่มต้นบนเบราว์เซอร์) | เครื่องเดียว/ทดลอง | สำรองข้อมูลสม่ำเสมอ |
| **PocketBase server** | หลายเครื่องใน**วง LAN** (โรงงาน/ร้าน) | ตั้ง server ตาม `README-POCKETBASE.md` แล้วกรอก URL เช่น `http://192.168.1.50:8090` |
| **Supabase (คลาวด์)** | หลายเครื่อง**ผ่านอินเทอร์เน็ต** | สร้างโปรเจกต์+รัน SQL ตาม `README-SUPABASE.md` แล้วกรอก URL + anon key |

ทุกโหมดมีปุ่ม **ทดสอบการเชื่อมต่อ** — เขียวก่อนค่อยกด **บันทึกและรีโหลด**

**ขั้นตอนย้ายข้อมูลไปโหมดใหม่:** ส่งออก (Export) จากโหมดเดิม → สลับโหมด+รีโหลด → นำเข้า (Import) ไฟล์ที่ส่งออกไว้

---

## 14. อัปเดตโปรแกรม

(เฉพาะแอป Windows) **ตั้งค่า → ที่เก็บข้อมูล → ⬆️ อัปเดตโปรแกรม**

1. กด **ตรวจหาอัปเดต** — ระบบเช็คเวอร์ชันใหม่จาก GitHub Releases
2. ถ้ามี → แสดงเลขเวอร์ชัน + รายละเอียด → กด **อัปเดตเดี๋ยวนี้**
3. โปรแกรมดาวน์โหลด ติดตั้ง และรีสตาร์ทเอง — **ข้อมูลไม่หาย** (อยู่ในไฟล์ SQLite แยกจากตัวโปรแกรม)

## 15. คำถามที่พบบ่อย & ข้อควรรู้

**Q: ออกใบกำกับภาษีไม่ได้ ขึ้นว่าเลขผู้เสียภาษีไม่ถูกต้อง**
A: ระบบตรวจ check digit จริงตามสูตรสรรพากร — เช็คเลข 13 หลักของ (1) บริษัทคุณใน ตั้งค่า→ข้อมูลบริษัท และ (2) ลูกค้าในหน้าลูกค้า ให้ครบถ้วนถูกต้อง ลูกค้าต้องมีที่อยู่ด้วย

**Q: พิมพ์เลขที่เอกสารเองแล้วระบบไม่ยอมบันทึก**
A: เลขนั้นถูกใช้ไปแล้ว — เลขที่เอกสารซ้ำผิดหลักเอกสารภาษี ระบบกันไว้ทุกกรณี (เลขอัตโนมัติจะข้ามเลขที่ถูกใช้แล้วให้เอง)

**Q: ลบใบเสร็จทิ้งเลยได้ไหม**
A: ต้อง**ยกเลิก (Void)** ก่อนเสมอ — ใบจะคงอยู่ในระบบพร้อมสถานะยกเลิกและคืนสต็อคให้ จากนั้นถ้าจำเป็นจริงจึงลบถาวรได้ (แนวปฏิบัติเอกสารภาษีที่ถูกต้อง)

**Q: สต็อคไม่ตรงกับของจริง**
A: ใช้ 🎯 **ตั้งยอดใหม่** ในหน้าจัดการสต็อค (นับของจริงแล้วใส่ยอด) — ประวัติจะบันทึกการปรับไว้ให้ตรวจสอบย้อนหลัง สาเหตุที่พบบ่อย: แก้บิลย้อนหลัง (ระบบไม่ปรับสต็อคให้), ออกใบส่งของ (ไม่ตัดสต็อคโดยออกแบบ)

**Q: ราคาสินค้ารวม VAT อยู่แล้ว ต้องตั้งยังไง**
A: ตั้งค่า → ใบเสร็จ → รูปแบบราคา → "**ราคารวม VAT แล้ว**" — ใบกำกับภาษีจะถอด VAT จากยอดขายให้ (107 = มูลค่า 100 + VAT 7) แทนการบวกเพิ่ม

**Q: เปิดสองแท็บ/สองหน้าต่างพร้อมกันได้ไหม**
A: ไม่ได้ในโหมดเบราว์เซอร์ (มีจอเตือน) — ถ้าต้องใช้หลายเครื่อง/หลายจอพร้อมกัน ให้ใช้โหมด PocketBase (LAN) หรือ Supabase (คลาวด์)

**Q: ใช้ offline ได้แค่ไหน**
A: แอป Windows ทำงาน offline ได้ 100% รวมถึงพิมพ์เอกสาร (ฟอนต์ฝังในตัว) — ยกเว้นโหมด Supabase ที่ต้องมีอินเทอร์เน็ต

**คีย์ลัด:** `Esc` ปิด modal/กล่องยืนยันได้ทุกจุด

## 16. สำหรับนักพัฒนา

```bash
npm install           # ติดตั้ง dependencies
npm run dev           # เว็บ dev server → http://localhost:5173
npm run build         # build production → dist/
npm run preview       # เสิร์ฟ production build

npm test              # unit tests (vitest) — 41 เทส
npm run test:e2e      # E2E (Playwright) — 10 สเปค build+รันเองอัตโนมัติ

npm run tauri:dev     # รันแอป desktop โหมดพัฒนา
npm run tauri:build   # build ตัวติดตั้ง Windows
```

**ปล่อยเวอร์ชันใหม่:** bump `version` ใน `src-tauri/tauri.conf.json` (+ `Cargo.toml`) →
commit → `git tag vX.Y.Z` → `git push origin main --tags` → GitHub Actions
(`.github/workflows/release.yml`) จะ build, เซ็น, และแนบ `latest.json` ให้ตัวอัปเดตอัตโนมัติเอง

เอกสารประกอบอื่น: `README-TAURI.md` (desktop) · `README-POCKETBASE.md` (LAN) ·
`README-SUPABASE.md` (คลาวด์) · `README-DEPLOY.md` (เว็บ) · `README-GITHUB-UPDATE.md` (ระบบอัปเดต)
